# INIT — Decisions and lessons

## Core logic lives in a separate Swift Package, not the Xcode app target

`AIControlCore` (models, `.project` parsing, folder scanning) is its own SPM
package at the repo root, with `swift test` running its unit tests. The
Xcode app (`App/`, generated by `xcodegen`) depends on it as a local
package.

**Why:** `swift build`/`swift test` are fast and need no simulator or Xcode
GUI, which matters a lot for an AI-driven workflow — the whole point of this
app is letting Claude Code iterate on itself quickly. Keeping domain logic
out of the app target also matches CLAUDE.md principle 4 ("modular code...
so AI can always work in an isolated context").

**How to apply:** any new non-UI logic (scanning, parsing, secrets diffing,
CLAUDE.md drift detection, etc.) goes in `AIControlCore` with tests. The
`App/` target should stay thin — SwiftUI views and glue only.

## `App/project.yml` is committed, the generated `.xcodeproj` is not

xcodegen regenerates the Xcode project from `project.yml` on demand
(`xcodegen generate`). The generated `.xcodeproj` is gitignored.

**Why:** avoids committing generated/binary-ish project files that produce
noisy diffs and merge conflicts; `project.yml` is the actual source of
truth and is easy for Claude Code to edit directly.

**How to apply:** anyone (human or AI) checking out the repo must run
`xcodegen generate` inside `App/` before opening/building the project.

## `.project`'s `claude_md_generated` is `null` for AI Control itself

The global module-merge system (`PROJECT.md` §6.2) that generates
per-project `CLAUDE.md` files doesn't exist yet — this project is what
builds it. AI Control's own `CLAUDE.md` was hand-written up front instead.

**Why:** bootstrapping problem — the tool can't generate its own
instructions before it exists.

**How to apply:** once Phase 6 (global config + CLAUDE.md generation) is
built, revisit whether AI Control should manage its own `CLAUDE.md` through
its own module system, or keep it hand-authored permanently as a special
case.
